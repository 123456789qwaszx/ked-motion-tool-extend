# ked-motion-tool

**컷**을 만드는 저작 도구. 컷 = 씬(계층 구조의 오브젝트들) + 카메라 + 정해진 길이의 타임라인이고, 게임은 컷 파일(`cut/1`)을 읽어 재생한다.
방향과 단계는 [`docs/PLAN-standalone.md`](docs/PLAN-standalone.md), 지금 어디인가는 [`docs/STATUS.md`](docs/STATUS.md).
인수인계는 [`docs/HANDOFF.md`](docs/HANDOFF.md), 사용법은 [`docs/USER-GUIDE.md`](docs/USER-GUIDE.md),
유지보수는 [`docs/MAINTENANCE.md`](docs/MAINTENANCE.md).

- 툴이 여는 것은 문서 안의 **컷**과 **세트**(묶어서 다시 쓰는 것)뿐이다. 새 문서는 비어 있고 **새 컷**이 들어가는 문이다.
- 마야급 커브 편집(그래프 에디터 · 도프 시트 · 타임 슬라이더)으로 오브젝트와 카메라의 키를 잡는다.
- 툴은 Yarn·커맨드를 **모른다**.

## 컷 (`docs/PLAN-standalone.md`)

이 툴의 단위는 **컷**이다: 씬(계층 구조의 오브젝트들) + 카메라 + 정해진 길이의 타임라인. 캐릭터·배경·소품이 전부 오브젝트이고, 그 기간의 움직임을 키프레임으로 잡는다.

- 왼쪽 맨 위 **컷** 목록 → **새 컷**(240프레임 = 10초). 열리면 오브젝트를 바로 놓는다 — 하이어아키 우클릭(오브젝트 · 그림 · 색 사각형), **그림 가져오기…**, **층 표 가져오기…**.
- **컷 이름** · **길이(프레임)** · **카메라**(당기기 · 밀기 X · 밀기 Y)는 컷 목록 아래의 칸에서.
- 컷을 열면 **타임라인이 바로 붙는다**. 키 없는 오브젝트는 끌면 가만히 선 자리가 바뀌고(키가 안 생긴다), 키가 있는 값은 손잡이·채널 박스로 포즈를 잡아 키를 놓는다.
- **카메라는 같은 타임라인의 트랙**이다 — 카메라 칸 옆의 **키**가 지금 프레임에 카메라의 키를 놓는다(그래프에 `Camera_Pan` · `Camera_Zoom`으로 보인다). 키가 놓인 뒤로는 칸을 고치는 것이 그 프레임의 키가 된다.
- 컷의 타임라인은 키가 처음과 끝에 없어도 되고 하나뿐이어도 된다.
- **끌어서 키**: 키가 있는 값을 끌어 놓으면 지금 프레임의 키가 된다(자리 · Shift 배율 · Ctrl 회전).
- **깊이의 키**: 깊이 칸 옆의 **키** — 오브젝트가 키로 멀어지고 가까워진다(그래프에 `이름__depth`로 보인다).
- **그림 키**(표정 바꾸기): 그림을 그리는 오브젝트를 고르고 "모션" 탭의 **그림 키 추가 (지금 프레임)…** — 그 프레임부터 그림이 바뀌고 다음 그림 키까지 이어진다(사이값이 없는 계단 키).
- 맨 위 오브젝트를 고르면 오브젝트 칸에 **깊이**(depthLevel: far 0 · back 10 · mid 14 · front 16 · close 20)가 선다 — 멀수록 작게 보이고, 카메라에 덜 따라 움직이고, 뒤에 그려진다.
- **컷 내보내기…** — 연 컷을 컷 파일(`cut/1`)로 낸다. 게임이 읽는 것이다: 묶음은 오브젝트로 펼치고 재생 블록은 키로 구운 한 덩어리, 시각은 프레임.
  읽어서 "이 프레임의 모습"을 내는 계산은 `Ked.Presentation.Core/Cut/`의 `CutPlayer`다 — 툴의 미리보기와 같은 계산이라 툴에서 본 것이 게임에서 보인다.
- **세트**는 그 아래의 "묶어서 다시 쓰는 것"이다 — 컷에서 고른 오브젝트를 **새 세트로 빼기**로 묶고, 다른 컷에 **세트 넣기**로 놓는다.

## 처음 써 보기 (10분)

1. **실행** — 저장소 루트에서:
   ```
   dotnet run --project src/Mt.App/Mt.App.csproj
   ```
   빈 무대가 뜬다("컷을 열거나 새로 만든다").
2. 왼쪽 맨 위 **새 컷** — `cut`(240프레임 = 10초)이 생겨 열리고 타임라인이 붙는다.
3. **오브젝트 놓기** — 하이어아키(왼쪽 "오브젝트")에서 우클릭 → **색 사각형 더하기**, 또는 PNG를 뷰포트에 끌어다 놓는다(**그림 가져오기…** · **층 표 가져오기…**도 같다). 끌어서 자리를 잡는다(Shift 배율 · Ctrl 회전).
4. **키** — 오브젝트를 고르고 **S**(지금 값이 지금 프레임의 키가 된다), 프레임을 옮겨 채널 박스에 값을 넣거나 손잡이(W/E/R)로 포즈를 잡고 다시 **S**. **Auto Key**를 켜면 놓는 순간 키가 된다.
   카메라는 컷 목록 아래 카메라 칸 옆의 **키**, 깊이는 "오브젝트" 탭 깊이 칸 옆의 **키**.
5. **Alt+`** 로 처음부터 재생. 그래프 탭에서 키를 끌어 본다 — 놓는 순간 뷰포트가 따라오고, Ctrl+Z로 돌아온다. 도프 시트 탭에서 블록을 끌면 시간이 옮겨진다.
6. **다른 이름으로…** → `*.motion-authoring.json`으로 저장(저작 원본). **컷 내보내기…** → 게임이 읽는 컷 파일(`*.cut.json`).

## 구조

```
Ked.Presentation.Core (복사 반입)  ──►  Mt.Authoring  ──►  Mt.App (Avalonia)
tests: Ked.Presentation.Core.Tests(NUnit, 원본 그대로) · Mt.Authoring.Tests(xunit) · Mt.App.Tests(Avalonia.Headless)
```

| 프로젝트 | 역할 |
|---|---|
| `src/Ked.Presentation.Core` | 무대 런타임의 연출 코어 복사본. 모션 규약·수학·검증·리그 수학의 유일한 출처. 출처와 동기화 절차는 [`vendoring.md`](src/Ked.Presentation.Core/vendoring.md) |
| `src/Mt.Authoring` | 저작 도메인. Avalonia를 모른다. `Model/`(저작 원본 `*.motion-authoring.json`) · `Editing/MotionEditor`(모든 편집의 통로, 스냅샷 undo) · `Serialization/`(`MotionDocumentJson` 저작 원본, `MotionsJson` 산출물 `motions/2` 정규 쓰기·관용 읽기) · `Validation/`(코어 `MotionRules`로 편집 중 검증, 0건일 때만 내보내기) · `Rig/RigAssets`(문서의 세트·컷을 세운 리그 한 벌) · `Preview/CutStage`(컷의 카메라와 깊이) |
| `src/Mt.App` | 그리기와 입력. `Views/ViewportView`(무대 — 연 컷이나 세트 하나를 세운다. 포즈는 `Mt.Authoring/Preview`의 코어 수학, 재생 시계·스크럽) · `Views/DopeSheetView`(도프 시트) · `Views/GraphEditorView`(그래프 에디터 — 드래그 중간값은 렌더만, 놓는 순간이 편집 하나) · `MainWindow`(셸: 컷·세트·하이어아키·모션 목록, 인스펙터, 파일) · `Services/DocumentSession`(경로·세운 리그·저장·내보내기). 좌표 변환·히트 테스트·탄젠트 산수는 `Mt.Authoring/Graph`의 순수 함수다 |

## 그래프 에디터 (마야 그래프 에디터 그대로)

아래 "그래프" 탭. 왼쪽 **아웃라이너** · 위 **툴바** · 회색 플롯(재생 범위 안은 밝게, 위 눈금자는 **프레임**, 값은 왼쪽, 현재 시각은 노란 선과 마커). 시간 표시는 설정에서 초로 바꿀 수 있다(칸에는 `12`·`12f`·`0.5s`처럼 단위를 붙여 쓸 수 있다).

| 조작 | 뜻 |
|---|---|
| 아웃라이너 | 모션의 채널이 **노드 · 종류**로 서고, 그 밑에 그 종류의 성분 전부(없는 것은 흐리게). 채널 이름 클릭 = 그 채널의 커브만(Shift/Ctrl: 더하기) · 성분 클릭 = 그 커브만 · **흐린 성분을 클릭해도 성분은 생기지 않는다**(마야식 — 성분은 키를 놓을 때만 생긴다) · 성분 행의 × = 그 성분만 삭제(마지막 성분이면 채널이 없어진다) · 채널 행의 🔓/🔒 · 🔊/🔇 · ×(성분 전부). 검색은 노드 이름·종류 |
| 클릭 · Shift+클릭 · 빈 자리 드래그 · Ctrl+드래그 | 키 선택 · 추가 선택 · 박스 선택 · 라소. 박스에 키가 들면 **키만**(커브는 하얘지지 않는다), 키 없이 커브만 지나면 커브 선택. 키를 고른 채 **탄젠트 핸들 끝을 박스로** 고르면 핸들 선택(키 선택은 그대로) |
| **커브 선 클릭** · Shift+클릭 · **박스 드래그가 커브를 지나면** | 커브 선택(흰색 굵게) · 더하기/빼기 · 정확히 안 눌러도 상자가 지나는 커브가 선택된다. 빈 자리 클릭은 푼다 |
| 커브를 고른 채 **MMB 클릭** | 그 커브 위, 그 시각(스냅)에 키(값은 곡선 위) — 마야 Insert Key |
| 선택 키 둘레에서 **RMB 드래그** · **Shift+RMB 드래그** · 빈 자리 **RMB 드래그** | 처음 움직인 쪽으로만(가로 = 시각, 세로 = 값) 한 번에 이동 · Shift면 정수 프레임(1fr, 2fr…)·정수 값에 스냅 · 화면 이동(팬) |
| **MMB 드래그** (어느 툴이든) · 이동 툴(**W**)의 LMB 드래그 · Shift = 축 잠금 | 선택 키 시간·값 이동(마야). 그래프의 팬은 RMB뿐. 핸들을 고른 상태면 **그 핸들들을 돌린다**(편집 하나). 선택 툴(**Q**)의 LMB는 고르기만. 시간은 스냅, 값은 **값 스냅**을 켜면 정수 |
| 스케일 툴(**R**) LMB 드래그 · Shift = 한 축만 | 선택 중심(피벗) 기준 값·시간 스케일 — 오른쪽 = 시간, 위 = 값 |
| **리전 툴**(툴바 "리전" 토글) | 상자로 고르면 상자가 남는다. 상자 안 드래그 = 이동, 왼/오른 모서리 = 반대쪽 끝 기준 시간 스케일, 위/아래 모서리 = 값 스케일. 다시 누르면 선택 툴(Q)로 |
| 위 눈금자 클릭·드래그 | 스크럽 |
| **I** · **A** · **F** · 툴바 재생 범위 | 현재 시각에 키(값은 곡선 위) · 전체 맞춤 · 선택 맞춤 · 재생 범위 맞춤(마야 Frame All / Frame Selected / Frame Playback Range). 툴바에는 재생 범위만 — 선택(Q)·이동(W)·스케일(R)·끼우기·전체·선택·현재 시각 가운데 버튼은 뺐다(소유자) |

| 툴바 버퍼 찍기/바꾸기(한 버튼) · 버퍼 지우기 · **Ctrl+B** · **Ctrl+Shift+B** | 버퍼가 없으면 보이는 커브를 흐린 점선으로 찍어 두고, 있으면 찍어 둔 것과 지금을 바꾼다(마야 Buffer Curve). 새로 찍으려면 지운 뒤 |

| 툴바 값 칸 `+=3` `-=1` `*=2` `/=2` | 선택 키 전부에 상대 적용(마야 채널 박스). 숫자는 절대값. 시각·기울기 칸은 없다 — 시각은 끌거나 도프 시트로, 기울기는 탄젠트 핸들로 |
| **Ctrl+C / X / V** (창 어디서나, 그래프·도프 시트 공용) | 복사 · 잘라내기 · 현재 시각에 붙여넣기(가장 이른 키를 현재 시각에, 같은 시각은 덮어씀, 없는 채널은 만든다). **붙이는 커브**: 고른 커브 선이 있으면 그것, 없고 복사한 커브가 안 보이면(아웃라이너에서 다른 커브만 띄운 상태) 보이는 커브, 그 밖에는 복사한 커브 — 그래서 scale X의 키를 복사해 scale Y만 띄우고 붙이면 Y에 들어간다(복사한 커브가 하나면 모든 대상에, 여럿이면 순서대로 짝) |
| 더블클릭 · **Delete** | 커브 위 그 시각에 키 · 키 삭제 (되돌리기는 전역 Ctrl+Z/Y) |
| 휠 (Ctrl = 시간만 · Shift = 값만) · 빈 자리 **RMB 드래그** · **Alt+MMB** · **Alt+RMB 드래그** | 줌 · 팬 · 팬 · 줌 드래그(오른쪽 = 시간, 위 = 값) |

## 타임 슬라이더 · 레인지 슬라이더 · 트랜스포트 (마야 그대로)

뷰포트 아래 두 줄. 위 줄은 **타임 슬라이더**(재생 범위를 프레임 눈금으로, 빨간 키 틱, 현재 프레임은 검은 상자) + `[현재 프레임] ⏮ |◀ ◁ ◀ ▶ ▷ ▶| ⏭`. 아래 줄은 `[0][범위 시작] ═레인지 바═ [범위 끝][길이]` + 재생 모드 · 속도 · 24 fps · **Auto Key**.

| 조작 | 뜻 |
|---|---|
| LMB 클릭·드래그 | 스크럽(프레임 스냅). 빨간 범위 선택은 지워진다 |
| **Shift+LMB 드래그** | 범위 선택(빨강, 프레임 단위). 한 프레임만 고르면 그 프레임의 키가 선택된다 |
| 범위 안 **MMB 드래그** · 범위 양끝 LMB 드래그 | 범위의 키 이동 · 반대쪽 끝 기준 시간 스케일(놓을 때 편집 하나, 끄는 동안 노란 유령 틱) |
| 범위 밖 **MMB 드래그** | **포즈 들고 스크럽** — 보이는 포즈는 그대로 두고 시각만 간다(현재 프레임 상자에 점선 테두리). **S**로 그 포즈를 그 프레임에 키(모든 채널, 되돌리기 한 번) · Esc/보통 스크럽은 버린다 |
| RMB 메뉴 | 키 잘라내기/복사/붙여넣기/삭제(범위, 없으면 현재 프레임) · 키를 프레임에 스냅 · 재생 범위를 선택으로/전체로 · 범위 선택 지우기 · 재생 모드 · 재생 속도 · 키 틱 표시(전체/선택/없음) |
| 레인지 바 끌기 · 양끝 · 더블클릭 | 재생 범위를 통째로 옮기기 · 크기 · 전체 ↔ 직전 범위 |
| 길이 칸 | 모션 길이(애니메이션 끝). 바꾸면 길이가 바뀐다 |
| ◀ · ▶ | 거꾸로 재생 · 재생(한 번/루프/왕복 모두 거꾸로 된다) |
| 재생 표시: 연속 / 프레임 맞춤 (24 FPS) | 둘 다 실제 시간으로 재생한다. **연속**은 실제 경과 시간에 해당하는 자세를, **프레임 맞춤**은 표시 시각을 가장 가까운 24 FPS 프레임에 맞춘 자세만 보여준다(느린 환경에서는 중간 프레임을 건너뛸 수 있다). 기본은 연속. 설정에 남는다 |

## 스킨 · 조각 그림 (`docs/PLAN-parts.md` P1)

그림을 그리는 오브젝트(조각)는 **스킨**으로 그림을 받는다 — Spine의 슬롯·어태치먼트·스킨과 같은 모양이다.
스킨 = 조각마다 붙일 그림의 묶음에 붙인 이름("땀"·"꽃"). 그림 오브젝트가 있는 컷이나 세트를 열면 "오브젝트" 탭 아래에 스킨 칸이 선다:
입혀 보는 스킨 고르기(보기 상태 — 문서를 안 바꾼다) · 스킨 추가/삭제 · 이름 · 조각마다 그림(경로를 적거나 `…`로 고른다). 그림을 안 준 조각은 안 그려진다.
조각은 보통의 오브젝트라 애니메이션이 조각마다 따로 움직인다.
**구조는 툴이 정의한다**(Spine처럼 툴이 원본 — `docs/PLAN-parts.md` §9). 세트는 문서 안에 정의되고(`rigs`), 왼쪽 **세트** 목록에서 열어 고친다.
그 아래 **rigs.json…** 은 세트를 리그 스키마 모양으로 내보낸다(옛 산출물 — `motions.json`과 함께).

**스킨의 덧붙임(그림 넘기기 · 놓임).** 스킨 칸의 그림 칸에 `art/a.png | art/b.png | art/c.png`처럼 여러 장을 이어 적으면 그 조각이 **장당 시간마다 넘어간다**
(되풀이하거나, 끄면 마지막 장에서 멈춘다 — 점이 하나씩 찍히는 말풍선). 그 아래 **놓임**(X · Y · 크기 · 회전)은 조각이 노드 안 어디에 얼마만 하게 놓이는가다 —
꽃 셋을 흩어 놓는 것은 스킨에서, 움직임은 모션에서. 그래서 같은 '톡 튀어나옴' 모션을 어느 스킨에나 쓴다.
그래프 목록 아래 **키 없음**에는 그 모션이 아직 안 건드리는 채널이 흐리게 선다 — 이름을 누르면 그 노드가 골라지고, **＋**는 지금 값에 키를 놓아 채널을 만든다(배율만 있는 모션에 위치를 조금 더하는 식).

**세트(`docs/PLAN-set.md`).** 왼쪽 맨 위의 **세트** 목록 — 세트는 오브젝트들의 계층 + 그림 + 애니메이션들의 한 덩어리다(화면 이동 하나, 소품 무리 하나…). 데이터로는 툴이 정의한 리그다.
**새 세트**로 만들거나 목록에서 고르면 **뷰포트와 하이어아키가 그 세트만** 보인다(**닫기**로 닫는다). 하이어아키에서 우클릭해 오브젝트를 더하고(묶음 · 그림)
순서·부모를 바꾸고 지운다(Del). 오브젝트를 고르면 "오브젝트" 탭 맨 위의 **오브젝트** 칸에서 이름·부모·X·Y·너비·높이와 "그림을 그린다 / 불투명도를 받는다"를 고친다.
이름을 바꾸면 그 세트의 애니메이션 채널·스킨 칸이 따라온다. 그 세트의 모션을 고르면 세트가 그 자리에서 연기한다.

**배치 모드.** 세트를 열고 모션을 안 골랐으면 뷰포트의 끌기는 키가 아니라 **가만히 선 자세**다 — 오브젝트를 집어 **끌면 자리, Shift+끌기는 배율, Ctrl+끌기는 회전**(끈 하나가 되돌리기 한 번).
**그림 가져오기…** 또는 PNG를 뷰포트에 끌어다 놓으면 그 자리에 그림 오브젝트가 선다(이름은 파일에서, 크기는 그림의 크기). 스킨 칸의 **입은 스킨**으로 그 세트의 스킨들을 갈아 입혀 본다(보기 상태).
그 세트의 모션을 고르면 애니메이션 모드가 되어 끌기가 키를 놓는다.

**층 표 가져오기.** 그림 한 묶음을 세트로 한 번에 — 세트 줄의 **층 표 가져오기…** 가 `layers.tsv`(줄마다 `파일 ⇥ 왼쪽 ⇥ 위 ⇥ 너비 ⇥ 높이`, 뒤에서 앞으로. `#`로 시작하는 설명 줄에 `#RRGGBB`가 있으면 바탕색)를 읽어
층마다 그림 오브젝트를 그 자리에 세우고 스킨에 그림을 준다(바탕색은 맨 뒤의 색 사각형). 되돌리기 한 번.

**시차와 무대만 보기.** 층 여럿이 차례로 들어오게 할 때: 세트의 애니메이션을 고른 채 하이어아키에서 오브젝트를 우클릭 → **움직임 밀기**(그 오브젝트의 키를 통째로 0.05 · 0.1 · 0.2초 늦게/일찍) ·
**여기서부터 차례로**(그 오브젝트와 뒤의 형제들에 그만큼씩 시차). 길이는 그대로이고 비는 쪽은 가만히 있는다. 재생 줄의 **무대만**을 켜면 무대 밖이 다 가려져 게임에서 보이는 그대로 본다.
**제 차례 전까지 숨기기**(같은 메뉴): 가만히 선 자세는 다 보이는 것이라, 늦게 나오는 오브젝트는 제 차례 전에 숨겨 둬야 한다 — 그 불투명도 키를 대신 놓는다(움직이기 시작하는 시각까지 0, 0.1초에 걸쳐 나타남).
**움직임을 마치면 숨기기**는 퇴장용, **전부: 제 차례 전까지 숨기기**는 늦게 나오는 오브젝트 전부를 한 번에.

**세트가 세트를 품는다.** 세트 보기의 하이어아키 우클릭 → **세트 넣기 ▸ (세트)** — 다른 세트의 인스턴스가 선다(참조: 그 세트를 고치면 여기도 바뀐다). 인스턴스의 자리·배율·회전·불투명도가 품은 것을 통째로 옮기고,
안쪽의 오브젝트들은 `인스턴스.이름`으로 하이어아키에 흐리게 보인다(안쪽은 그 세트를 열어 고친다). 뷰포트에서 안쪽을 눌러도 인스턴스가 집힌다. 서로 품거나 품긴 세트를 지우는 것은 막는다.
산출물 `rigs.json`에는 **펼친 한 덩어리**로 나간다 — 런타임은 달라질 것이 없다.

**재생 블록 — 품은 세트의 애니메이션을 튼다.** 세트를 품은 세트의 애니메이션을 고르면 "모션" 탭 아래에 **재생 블록** 칸이 선다. **재생 블록 추가 (지금 시각)** → 줄마다 시각 · 인스턴스 · 애니메이션 · 반복 · ×.
유지(commit) 애니메이션은 끝난 자세가 남고(되풀이하면 바퀴마다 쌓인다), 복원(restore)은 시작 전으로 돌아간다. 같은 인스턴스의 블록끼리는 겹칠 수 없고 이 애니메이션의 길이 안에 들어야 한다.
참조다 — 품은 애니메이션을 고치면 여기도 따라온다. 바깥 애니메이션이 같은 경로(`car.Wheel`)에 제 키를 놓으면 그 성분은 제 키가 이긴다. 품은 애니메이션의 이벤트 키도 그 시각에 울린다.
산출물 `motions.json`에는 **구운 한 덩어리 모션**으로 나간다(블록의 처음·끝에서 값이 튀는 자리는 1/240초짜리 선으로 잇는다) — 런타임은 재생 블록을 모른다.
줄의 **떼기**는 그 인스턴스의 블록들을 이 애니메이션의 제 키로 굳힌다(재생은 그대로, 그 뒤로는 원본을 안 따른다 — 여기서만 다르게 고칠 때). 블록이 도는 구간은 타임 슬라이더 아래쪽의 보라색 막대로 보이고, **막대를 끌면** 시작 시각이 옮겨진다.

**다른 문서의 세트 들이기.** 세트 줄의 **다른 문서에서…** — 다른 저작 문서의 세트(품은 세트까지)와 그 애니메이션·스킨이 통째로 온다. 그림은 복사하지 않고 그 문서의 자리를 가리킨다. 같은 이름이 이미 있으면 막힌다.

**세트를 가른다 — 새 세트로 빼기.** 한 덩어리로 지은 세트에서 하이어아키 우클릭 → **새 세트로 빼기 ▸ 이것만**, 또는 함께 뺄 형제를 체크하고 **체크한 것과 함께 뺀다**(떨어져 있어도 된다) — 고른 오브젝트들(과 그 밑)이 새 세트가 되고 그 자리에 인스턴스가 선다.
자리(고른 것들의 가운데가 새 세트의 가운데) · 그림(스킨 칸) · 키(채널이 새 세트의 애니메이션으로 가고, 원래 애니메이션에는 그것을 트는 재생 블록이 선다)를 데리고 간다 — **보이는 것은 그대로다**. 되돌리기 한 번.
새 세트의 이름은 첫 오브젝트에서 온다 — 세트 목록 아래 **세트 이름** 칸에서 고친다(그 세트의 애니메이션·스킨, 품은 곳이 따라오고, 세트의 이름을 딴 애니메이션 `옛이름_x` · 스킨 · 인스턴스의 이름도 함께 바뀐다).
인스턴스를 고르면 "세트의 오브젝트" 칸에 **안쪽 스킨**과 **안쪽 세트 열기 ▸**가 선다 — 들어가서 고치고 **◂ 돌아가기**로 돌아온다.
**바깥을 보는 채로 안쪽 고치기**: 배치 모드에서 품은 세트를 **더블클릭**(또는 **여기서 안쪽 고치기**)하면 안쪽의 오브젝트가 집힌다 — 끌면 품은 세트의 자리·배율·회전이 바뀐다(둘레의 것과 맞춰 보며). Esc · 빈 곳 더블클릭으로 나온다.

**화면 밖에서 들어온다.** 애니메이션을 고른 채 하이어아키 우클릭 → **화면 밖에서 들어온다 / 화면 밖으로 나간다 ▸ 왼쪽 · 오른쪽 · 위 · 아래** — 그 오브젝트가 무대 밖으로 다 나가는 거리를 세어, 지금 시각부터 0.5초의 자리 키로 놓는다.

**색 사각형.** 하이어아키 우클릭 → **색 사각형 더하기** — 그림 없이 너비 × 높이를 한 색으로 채우는 오브젝트다(화면 전환·소개의 패널). 색은 "세트의 오브젝트" 칸의 **색**(옆의 견본 단추로 고르거나)에 `#RRGGBB`(또는 `#RRGGBBAA`)로 적는다.
스킨이 없어도 서고, 그림 오브젝트와 한 순서로 겹쳐 그려진다. 산출물 `rigs.json`에는 그 노드의 `fillColor`로 나간다.

**애니메이션 모드와 따로 보기.** 세트를 연 동안 모션 목록은 **그 세트의 애니메이션만** 보인다("모션 추가"도 그 세트의 것을 만든다). 하나를 고르면 끌기·채널 박스·S·Auto Key·그래프가 그 애니메이션에 키를 놓고,
선택을 풀면 배치 모드로 돌아간다. 하이어아키에서 오브젝트를 우클릭해 **이것만 보기(솔로)** · **숨기기** · **전부 보이기** — 오브젝트를 하나씩 따로 보며 돌려 본다(보기만 바뀐다: 문서는 그대로).

**불투명도(P4, `motions/3`).** 불투명도도 모션의 채널이다(종류 `alpha`, 0~1, 성분 하나). 불투명도를 받을 수 있는 오브젝트("불투명도를 받는다"를 켠 것)를
하이어아키에서 고르면 "모션" 탭에 **불투명도** 칸이 선다 — 값을 넣고 Enter = 그 시각에 키, 커브는 그래프에서. 상대값은 곱(지금 불투명도 × 키), 절대값은 키 그대로.
부모 노드의 불투명도와 곱해져 그려지므로 묶음 전체(부모 노드)와 조각 하나를 따로 흐릴 수 있다. 알파 채널이 든 문서는 `motions/3`으로 나가고,
없으면 전과 같은 `motions/2`다. 이 채널은 툴이 먼저 지은 규약이다 — 코어 사본에 선반영했고(`vendoring.md`), 런타임이 같은 모양으로 구현한다.

**이벤트 키(`motions/3`).** 모션의 한 시각에 "여기서 이것을 울린다"는 표시를 놓는다 — 재생이 그 시각을 지나는 순간 런타임이 (이름, 값)으로 알린다
(예: 이름 `sfx` · 값 `pop`). "모션" 탭 아래 **이벤트 추가 (지금 시각)**, 줄에서 시각·이름·값을 고친다. 타임 슬라이더에 초록 세모로 보이고,
뷰포트는 방금 울린 것을 `⚑ 이름 값`으로 잠깐 보인다. 상태가 아니라서 건너뛰기·되감기에서는 다시 울리지 않는다.
이름은 영문 소문자·숫자·`_`, 어떤 이름이 무엇을 하는지는 런타임이 정한다.

## 하이어아키 · 오브젝트 탭 · 월드 축

- **여는 것은 컷과 세트뿐이다.** 새 문서는 비어 있고, 아무것도 안 열었으면 뷰포트는 빈 무대(기준 해상도 1920×1080의 틀)다. 왼쪽 **컷** 목록의 **새 컷**, 또는 **세트** 목록의 **새 세트**로 시작한다. 둘은 하나만 연다.
- 왼쪽 **오브젝트** 하이어아키: 맨 위 항목이 연 컷/세트이고 그 밑이 오브젝트의 부모·자식 계층이다. **오브젝트를 클릭**하면 채널 박스·매니퓰레이터와 "오브젝트" 탭의 칸이 그것을 본다(키 따라가기는 꺼진다). 우클릭 = 더하기(오브젝트 · 그림 · 색 사각형) · 세트 넣기 · 따로 보기(솔로 · 숨기기) · 순서 · 부모 · 새 세트로 빼기 · 지우기. **Del** 지우기 · **F2** 이름 바꾸기. "채널 추가"는 없다 — 채널 박스에 값을 넣거나 끌면 첫 키에서 채널·성분이 생긴다.
- 오른쪽 **오브젝트 탭**: 고른 오브젝트의 이름 · 부모 · 깊이(컷의 맨 위 오브젝트만) · X · Y · 너비 · 높이 · 회전 · 배율 · 색 · "그림을 그린다 / 불투명도를 받는다", 품은 세트의 스킨과 **안쪽 세트 열기**, 그 아래 스킨 칸. 가만히 선 자세다 — 키가 아니다.
- **월드 축·격자**: 루트 공간(가운데 원점·y 위·px). 빨강 x·초록 y 축, 가는 선 1u(기준 폭/48 = 40px), 굵은 선 5u, 무대 프레임. 오브젝트는 무대 프레임 밖도 잘리지 않고 그대로 그리며, 카메라에 안 잡히는 바깥은 회색으로 덮어 가른다(**무대만**을 켜면 다 가린다).
- **깊이와 카메라**는 컷의 것이다(위 "컷") — 깊이 커브는 런타임 `ExportedTuning/presets/depth.json`의 사본이 내장되어 있다(`Mt.Authoring/Defaults`, 원본 커밋은 `BuiltinTuning.Source`). 세트는 깊이·카메라 없이 무대 가운데에 그대로 선다.
- **모션 목록**: 컷을 열면 그 타임라인 하나, 세트를 열면 그 세트의 애니메이션들. 아무것도 안 열었으면 문서의 모션 전부(주인이 사라진 것도 여기서 고르고 지운다). **모션 추가**는 연 세트의 애니메이션을 만든다.
- 채널 종류는 화면에서 `position · scale · rotate`로 부른다(파일 규약은 `euler` 그대로). 세트의 애니메이션에는 모션 탭의 **종료 처리**(복원/유지)와 **재생 기준**(상대값/절대값)이 있다 — 옛 산출물(`motions.json`)로 나가는 것들의 규약이다. 컷의 타임라인은 그 프레임의 모습 그대로라 이 칸들이 잠긴다.
- 툴바의 **motions.json 가져오기… / 내보내기…** 와 세트 줄의 **rigs.json…** 은 옛 산출물이다. **내보내기 범위**: 전체 / 연 세트·컷의 것만 — 고른 모션의 문제만 내보내기를 막는다.
- 걷어 낸 속성이 든 옛 문서도 그대로 열린다 — 문서의 씬(`scenes` · `activeScene`), 리그 덤프 참조(`rigSchemas` · `baseResolution`), `preview.portrait` 같은 것은 읽을 때 무시되고 다시 저장하면 사라진다. 옛 설정 파일의 걷어 낸 항목도 마찬가지다.

## 뷰포트

- **보기(네비게이션)**: 휠 = 커서를 축으로 확대·축소(×1.15/칸, 0.2…10배) · **MMB·RMB 드래그** = 보기 이동 · **F**(뷰포트에 포커스) = 처음 자리(무대가 뷰포트에 맞게). 화면뿐이고 문서(오브젝트·카메라·키)는 안 바뀐다.
- **창 배치**: 왼쪽(컷·세트·하이어아키·모션) · 가운데 · 오른쪽(인스펙터·채널 박스) 사이의 세로 스플리터, 뷰포트와 그래프/도프 시트 사이의 가로 스플리터를 끌어 크기를 바꾼다. 타임 슬라이더·레인지 줄은 뷰포트에 붙어 늘 제 높이이고, 스플리터는 뷰포트와 그래프의 몫만 바꾼다. 폭과 비율은 설정 파일에 남아 다음에 열 때 그대로다.

- 오른쪽 패널은 **탭 셋** — **채널 박스**(기본) · **오브젝트** · **모션**(이름·길이·종료 처리·재생 기준). 마지막 탭은 설정에 남는다. 설정과 단축키 표는 패널이 아니라 툴바의 **설정…** · **단축키 (F1)** 창이다. 단축키의 그림자 버튼(Q/W/E/R·S·Esc·키 복사/붙여넣기·인비트윈)은 없다 — 하단 줄의 **Auto Key** 토글 하나만 남는다.
- **채널 박스**(마야): 하이어아키에서 고른 오브젝트의 **Translate X/Y · Rotate X/Y/Z · Scale X/Y**. 칸의 값은 지금 시각의 포즈(키 없는 포즈 포함)다. 값을 넣으면(`+=3`·`-=1`·`*=2`·`/=2`는 지금 값에 상대) 매니퓰레이터를 놓은 것과 같다: **Auto Key**거나 그 시각에 키가 있으면 키, 아니면 키 없는 포즈(S로 키·Esc로 버림). 칸 색: 빨강 = 이 시각에 키, 연한 빨강 = 어딘가에 키, 주황 = 키 없는 포즈. 이름 클릭 = 그 커브를 그래프에(Shift/Ctrl: 더하기), **●** = 그 성분을 지금 값으로 지금 키(마야 Key Selected). 채널·성분은 첫 키에서 생긴다.
- **S(키 놓기)**: 키 없는 포즈(드래그·채널 박스·MMB 스크럽)가 있으면 그것을 키로. 없으면 **고른 노드의 있는 성분을 지금 값으로 현재 시각에** 키(마야 Set Key on selected). 키 값은 재생 기준대로(상대값이면 시작값과의 차이). 컷의 타임라인과 세트의 애니메이션은 키가 하나뿐이어도 된다(앞뒤로 그 값이 이어진다).
- **매니퓰레이터**: **W** 이동 · **E** 회전 · **R** 배율 · **Q** 선택. 기즈모의 축 끝은 한 축만, 가운데는 자유. 이동은 화살표, 배율은 끝 상자, 회전은 고리(마야 모양). 손잡이는 오브젝트의 원점에 서되 원점이 그림 밖이면(발 기준으로 도는 묶음처럼) 그림 가운데에 선다. 배율은 팔 방향으로 끈 거리로 잰다 — 팔 하나만큼 밖이 ×2, 안이 ×0에 가깝고, 가운데를 지나도 다시 커지거나 뒤집히지 않는다. 놓는 순간 **Auto Key**면 키가 들어가고(바뀐 성분만), 아니면 "키 없는 포즈"로 남아 **S**로 키를 놓거나 **Esc**/시각 이동으로 버린다. 그 시각에 이미 키가 있으면 바로 덮어쓴다. 채널·성분이 없으면 만든다.
- 연 컷/세트의 오브젝트 계층으로 세운 트리(노드 키는 `set/이름`). 그림(스킨의 조각)이나 색이 있는 오브젝트는 그것으로 그려지고, 그릴 것이 하나도 없으면 무대의 윤곽과 이름으로 선다.
- 포즈 = 코어 `MotionMath.Compose`. 세트의 애니메이션은 길이를 지나면 restore는 시작 상태, commit은 마지막 키 — 재생도 그 규칙을 보여 준다.
- **Alt+Q** 재생/일시정지 · **Alt+`** 처음부터 재생 · **`** 첫 프레임 · **Home/End** 처음/끝 · **←/→** 한 프레임(24fps). 타임 슬라이더·그래프의 현재 시각과 하나다.
- 선택한 키의 노드에 피벗·x(빨강)·y(초록) 축.

## 명령줄 `mt` — 창 없이, AI·스크립트·CI용

`src/Mt.Cli`(실행 파일 `mt`). 저작 원본을 읽어 **검증·내보내기·그 시각의 포즈 조회**를 한다. 결과는 표준 출력의 JSON 하나, 사람에게 하는 말은 표준 오류,
종료 코드는 0 = 됨 · 1 = 막는 문제가 있다 · 2 = 쓰는 법이 틀렸다. 화면과 같은 함수를 지나므로 여기서 통과한 것은 앱에서도 통과하고, 여기서 읽은 포즈는 뷰포트가 보이는 포즈다.

```
dotnet run --project src/Mt.Cli -- info     a.motion-authoring.json
dotnet run --project src/Mt.Cli -- validate a.motion-authoring.json [--rig rig-schemas.json]
dotnet run --project src/Mt.Cli -- export   a.motion-authoring.json motions.json
dotnet run --project src/Mt.Cli -- pose     a.motion-authoring.json --motion nod --time 0.3 [--mode relative|absolute]
dotnet run --project src/Mt.Cli -- rigs     a.motion-authoring.json rigs.json
```

- `info`는 모션 · 스킨 · 컷 · 세트의 목록을 낸다.
- `pose`는 그 모션이 얹히는 세트·컷을 세워(컷이면 카메라와 깊이까지) 모션이 건드리는 노드의 값(위치·배율·회전·불투명도)과 방금(0.4초 안에) 울린 이벤트 키를 낸다 — AI가 "이 시각에 정말 이렇게 되나"를 읽는 자리다.
- 리그는 문서가 정의한 세트·컷으로 세운다. `--rig <rig-schemas.json>`을 주면 그 파일의 리그 위에 얹는다(옛 산출물을 확인할 때).
- **손으로(또는 AI가) 쓴 문서**는 키에 값과 탄젠트 **종류**(`auto`·`flat`·`linear`·`spline`·`plateau`)만 적으면 된다 — `mt`가 읽을 때 탄젠트 값을 세운다
  (앱이 편집할 때마다 하는 그 계산. `free`는 적힌 값 그대로). 앱이 저장한 문서에는 아무것도 안 바뀐다.

## 설정 · 저장

- **설정 창**(툴바 "설정…", 마야 Preferences): 시간 스냅 간격(1/24초 = 1프레임 기본 · 1/60 · 1/120) · 새 키 탄젠트 · 시간 표시 · 자동 저장. 바꾸는 즉시 적용, 닫을 때 저장. 시간 스냅 켬/끔과 값 스냅은 그래프 툴바에, Auto Key는 하단 줄에.
- 설정은 `%APPDATA%/ked-motion-tool/settings.json`(시간 스냅·시간 스냅 간격·새 키 탄젠트·Auto Key·시간 표시(프레임/초)·자동 저장 간격·창 배치·인스펙터 탭·최근 파일 8개). 창을 닫을 때 저장. 테마는 마야처럼 어두운 색 고정.
- **되돌리기**(`docs/PLAN-undo.md`): 조작 하나 = 되돌리기 한 칸 — 드래그 한 번, 값 칸 Enter 한 번, S 한 번(키 없는 포즈 전부). 같은 값을 다시 확정하거나 포커스만 옮기는 것은 기록도 다시하기 삭제도 아니다. **키 없는 포즈**(Auto Key 꺼짐)도 이력에 든다: 끌기·값 입력·Esc·스크럽·선택 변경·재생으로 생기고 사라진 포즈가 문서 조작과 한 줄에서 실제 순서대로 돌아오고, S로 키한 것을 되돌리면 키 확정 직전의 포즈로 돌아온다(저장 파일에는 안 들어간다). 세트·컷의 구조나 스킨의 그림을 되돌리면 뷰포트가 세운 것도 따라온다 — 그것이 바뀐 때만 다시 싣는다.
- 자동 저장은 문서 옆 `<이름>.autosave.motion-authoring.json`(기본 5분, 바뀐 것이 있을 때만). 저장 상태는 건드리지 않는다.
- 아래 문제 칸의 줄에 고칠 길이 있으면 **돕는 손** 버튼이 선다(이름 고치기 등). 각각 되돌리기 한 번. 빨강 ⚠는 규칙(내보내기를 막는다), 노랑 △는 알림(내보내기는 된다). 키의 값은 알리지 않는다 — 첫 키가 중립값이 아닌 것("지금 값 +140에서 시작")도, 복원이 중립값이 아닌 데서 끝나는 것도 뜻이다.
- 키가 있는 성분은 전부 내보낸다(상수 중립값도). 파일이 mode를 모르므로 "무변"인지 "그 값으로"인지 낼 때 정할 수 없다 — Unity 내보내기와 같은 규칙.
