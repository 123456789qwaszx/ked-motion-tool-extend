# ked-motion-tool 사용법

애니메이터·연출자용 안내. 설치부터 컷 내보내기까지, 그리고 화면별 조작 전부.
키 하나하나의 전체 표는 툴 안의 **단축키 (F1)** 창에도 있다.

## 1. 설치와 실행

| 방법 | 절차 |
|---|---|
| 소스에서 실행 | .NET 10 SDK 설치 → 저장소 루트에서 `dotnet run --project src/Mt.App/Mt.App.csproj` |
| 빌드만 | `dotnet build KedMotionTool.sln --configuration Release` |

처음 열면 **빈 문서**가 뜬다 — 컷도 세트도 없고 뷰포트는 빈 무대(1920×1080의 틀)다. 왼쪽 맨 위의 **새 컷**이 들어가는 문이다.

설정 파일은 `%APPDATA%\ked-motion-tool\settings.json`에, 자동 저장은 문서 옆 `<이름>.autosave.motion-authoring.json`에 남는다.

## 2. 화면 구성

```
┌ 툴바: 새로 · 열기… · 최근… · 저장 · 다른 이름으로… · motions.json 가져오기… · 내보내기… · 되돌리기 · 다시하기 · 설정… · 단축키 (F1)
├───────────────┬──────────────────────────────────┬──────────────────┐
│ 컷 목록 · 칸   │ 뷰포트 (무대·격자·오브젝트·매니퓰레이터)│ 인스펙터 탭 셋     │
│ 세트 목록      │                                  │  채널 박스 (기본)  │
│ 오브젝트       │ 타임 슬라이더 · 트랜스포트          │  오브젝트         │
│   하이어아키   │ 레인지 슬라이더 · 재생 모드 · Auto Key│  모션            │
│ 모션 목록      ├──────────────────────────────────┤                  │
│ 모션 추가/삭제 │ 그래프 / 도프 시트 탭              │                  │
├───────────────┴──────────────────────────────────┴──────────────────┤
│ 문제 칸 (규칙 위반 ⚠ · 경고 △ · 돕는 손 버튼)                              │
└─────────────────────────────────────────────────────────────────────┘
```

패널 사이의 스플리터를 끌어 크기를 바꾼다. 폭과 비율은 다음에 열 때 그대로다.

## 3. 10분 안에 한 번 해 보기

1. **새 컷** — `cut`(240프레임 = 10초)이 생겨 열린다. 타임라인이 바로 붙는다(컷에는 타임라인이 하나다).
2. **오브젝트 놓기** — 왼쪽 "오브젝트" 하이어아키에서 우클릭 → **색 사각형 더하기**(또는 **그림 오브젝트 더하기**). PNG를 뷰포트에 끌어다 놓아도 그림 오브젝트가 선다. 오브젝트를 끌어 자리를 잡는다(Shift+끌기 배율 · Ctrl+끌기 회전).
3. **키** — 오브젝트를 고르고 **S**: 지금 값이 지금 프레임의 키가 된다. 타임 슬라이더에서 프레임을 옮기고, 오른쪽 **채널 박스**의 Translate X에 값을 넣고 Enter, 다시 **S**.
4. **Alt+`** — 처음부터 재생. **Alt+Q**는 재생/일시정지.
5. 아래 **그래프** 탭에서 키를 **MMB 드래그**로 옮겨 본다. 놓는 순간 뷰포트가 따라오고 **Ctrl+Z**로 돌아온다. **도프 시트** 탭에서 블록을 끌면 시간만 옮겨진다.
6. **다른 이름으로…** → `*.motion-authoring.json`(저작 원본). 컷 목록의 **컷 내보내기…** → 게임이 읽는 컷 파일(`*.cut.json`).

## 4. 컷을 짓는다

1. **오브젝트** — 하이어아키 우클릭으로 더하고(묶기만 하는 오브젝트 · 그림 · 색 사각형), 순서·부모를 바꾸고, **Del**로 지운다. 고르면 오른쪽 **오브젝트** 탭에서 이름·부모·자리·크기·색을 고친다. 맨 위 오브젝트에는 **깊이** 칸이 선다 — 멀수록 작게 보이고 카메라에 덜 따라 움직이고 뒤에 그려진다.
2. **키** — 키가 없는 값은 끌면 가만히 선 자리가 바뀐다(키가 안 생긴다). 키가 있는 값은 끌어 놓으면 지금 프레임의 키가 된다. 하단 줄의 **● Auto Key**를 켜면 손잡이(**W** 이동 · **E** 회전 · **R** 배율)를 놓거나 채널 박스에 값을 넣는 순간 키가 들어간다. 꺼져 있으면 **키 없는 포즈**(주황)로 남고, **S**로 키를 놓거나 **Esc**로 버린다.
3. **카메라** — 컷 목록 아래 카메라 칸(당기기 · 밀기 X · 밀기 Y)과 그 옆의 **키**. 카메라는 같은 타임라인의 트랙이다(그래프에 `Camera_Pan` · `Camera_Zoom`). 깊이도 깊이 칸 옆의 **키**로 키를 놓는다.
4. **그림 키**(표정 바꾸기) — 그림 오브젝트를 고르고 "모션" 탭의 **그림 키 추가 (지금 프레임)…**.
5. **세트** — 여러 컷에 나오는 것은 하이어아키 우클릭 **새 세트로 빼기**로 묶고, 다른 컷에 **세트 넣기**로 놓는다. 세트는 왼쪽 **세트** 목록에서 열어 따로 고친다. 세트의 움직임은 "모션" 탭의 재생 블록으로 컷에 놓는다.

세트를 열었을 때는 **모션 추가**로 그 세트의 애니메이션을 만든다(이름 `motion`, 길이 1초 — 오른쪽 **모션** 탭에서 바꾼다).

### 종료 처리와 재생 기준 (세트의 애니메이션)

컷의 타임라인은 키가 그 프레임의 모습 그대로다 — 아래 두 칸은 세트의 애니메이션에만 있다.

| 항목 | 값 | 뜻 |
|---|---|---|
| 종료 처리 | 복원(Restore) | 길이를 지나면 시작 상태로 돌아간다. 마지막 키가 중립값이 아니어도 된다(끝에서 시작값으로 돌아간다 — 알리지 않는다). |
| 종료 처리 | 유지(Commit) | 마지막 키가 남는다 |
| 재생 기준 | 상대값(Relative) | 툴이 키를 "시작값 + 키"(배율은 ×)로 읽는다. 파일에는 안 나간다 — 실제 뜻은 대본의 `<<motion slot 이름 relative\|absolute>>`가 정한다 |
| 재생 기준 | 절대값(Absolute) | 키 그대로 |

## 5. 뷰포트

| 조작 | 뜻 |
|---|---|
| 휠 · **MMB/RMB 드래그** · **F** | 커서 축으로 확대/축소 · 보기 이동 · 처음 자리. 화면만 바뀌고 문서는 그대로 |
| 오브젝트 드래그 · Shift+드래그 · Ctrl+드래그 | 자리 · 배율 · 회전(키가 없는 값은 가만히 선 자세, 컷에서 키가 있는 값은 지금 프레임의 키). 품은 세트 더블클릭 = 안쪽 고치기 |
| **Q** / **W** / **E** / **R** | 선택 / 이동(화살표) / 회전(고리) / 배율(끝 상자). 축 끝은 한 축만, 가운데는 자유. 배율은 팔 방향으로 끈 거리 — 팔 하나만큼 밖이 ×2, 안이 0에 가깝고 가운데를 지나도 커지지 않는다 |
| **S** · **Esc** | 키 없는 포즈를 키로 / 버리기. 포즈가 없으면 S는 고른 노드의 있는 성분을 지금 값으로 현재 시각에 키 |
| `` ` `` · **Home/End** · **←/→** · **Alt+1/2** | 첫 프레임 · 처음/끝 · 한 프레임(24fps) |
| **Alt+Q** · **Alt+`** | 재생/일시정지 · 처음부터 재생 |

무대 프레임 밖의 오브젝트도 그대로 그리고, 카메라에 안 잡히는 바깥은 회색으로 덮인다. 격자는 1u = 40px(기준 폭/48), 굵은 선 5u.

## 6. 그래프 에디터 (마야 그래프 에디터와 같다)

왼쪽 아웃라이너(채널·성분), 위 툴바, 플롯(위 눈금자는 프레임, 재생 범위 안은 밝게, 현재 시각은 노란 선).

| 조작 | 뜻 |
|---|---|
| 클릭 · Shift+클릭 · 빈 자리 드래그 · Ctrl+드래그 | 키 선택 · 더하기 · 박스(키가 들면 키만, 커브만 지나면 커브) · 라소 |
| 커브 선 클릭 · Shift+클릭 | 커브 선택(흰색) · 더하기/빼기 |
| 커브를 고른 채 **MMB 클릭** · 더블클릭 · **I** | 그 커브 위, 그 시각에 키 끼우기 |
| **MMB 드래그** | 선택 키 이동(시간·값). 핸들을 골랐으면 핸들 회전. Shift = 축 잠금 |
| 선택 키 둘레 **RMB 드래그** · 빈 자리 **RMB 드래그** | 처음 움직인 축으로만 이동(Shift = 정수 프레임·값 스냅) · 팬 |
| **W** 이동 툴 · **R** 스케일 툴 · **Q** 선택 툴 | LMB 드래그로 이동 · 선택 중심 기준 스케일(오른쪽 = 시간, 위 = 값) · 고르기만 |
| 툴바 **리전** 토글 | 상자가 남는다. 안 = 이동, 좌우 모서리 = 시간 스케일, 상하 = 값 스케일. 다시 누르면 선택 툴로 |
| 탄젠트 핸들(선택 키 양쪽 흰 선) | 끝을 LMB로 끌어 기울기. 박스로 고르면 MMB로 돌린다 |
| 툴바 auto · spline · linear · flat · plateau · 끊기 · 붙이기 · **Ctrl+1…6** | 선택 키 탄젠트(4 = free는 버튼 없음) |
| 툴바 버퍼 찍기/바꾸기 · 지우기 · **Ctrl+B** · **Ctrl+Shift+B** | 보이는 커브를 흐린 점선으로 찍어 두고 지금과 바꾼다 |
| 툴바 무한(앞·뒤) | 상수 / 사이클 / 사이클+오프셋 / 왕복 / 직선 — 보기만(산출물의 끝은 종료 처리) |
| 툴바 값 칸 `+=3` `-=1` `*=2` `/=2` | 선택 키 전부에 상대 적용. 숫자는 절대값 |
| **Ctrl+C / X / V** · **Delete** | 복사 · 잘라내기 · 현재 시각에 붙여넣기 · 삭제 |
| 휠(Ctrl = 시간만, Shift = 값만) · **Alt+MMB** · **Alt+RMB** | 줌 · 팬 · 줌 드래그 |
| **A** · **F** · 툴바 재생 범위 | 전체 맞춤 · 선택 맞춤 · 재생 범위 맞춤 |
| 툴바 시간 스냅 · 값 스냅 | 키 배치·이동·스크럽 시 시간을 간격(기본 1/24초)의 배수에 · 값을 정수에 |

아웃라이너에서 채널 이름(노드 · 종류) 클릭 = 그 채널의 커브만(Shift/Ctrl: 더하기), 성분 클릭 = 그 커브만. 흐린 성분은 키가 없는 것이라 클릭해도 생기지 않는다(키를 놓을 때 생긴다). 성분 행의 × = 그 성분 삭제, 채널 행의 🔓/🔒 · 🔊/🔇 · × = 잠금 · 뮤트 · 채널 삭제.

## 7. 도프 시트

그래프와 **선택이 하나**다.

| 조작 | 뜻 |
|---|---|
| 블록 클릭 · Shift · 박스 | 선택. 요약 행의 블록 하나는 그 밑의 키 전부 |
| 블록 드래그 · Alt+드래그 · **Ctrl+D** | 시간 이동 · 복제 · 한 프레임 뒤에 복제 |
| 범위 띠 양끝 핸들 | 시간 스케일(반대쪽 끝이 기준) |
| 성분 행 더블클릭 · **Delete** | 그 시각에 키 · 삭제 |
| 눈금자 클릭·드래그 · 노드 행 클릭 · 휠 · MMB · **A** | 스크럽 · 접기 · 시간 줌 · 팬 · 전체 맞춤 |

움직인 키가 안 움직인 키의 시각에 닿으면 움직인 키가 이긴다. 시간은 0 아래로 안 내려간다.

## 8. 타임 슬라이더 · 레인지 슬라이더

| 조작 | 뜻 |
|---|---|
| LMB 클릭·드래그 | 스크럽(프레임 스냅) |
| **Shift+LMB 드래그** | 빨간 프레임 범위 선택. 한 프레임만 고르면 그 프레임의 키 선택 |
| 범위 안 **MMB 드래그** · 범위 양끝 LMB | 범위의 키 이동 · 반대쪽 끝 기준 시간 스케일 |
| 범위 밖 **MMB 드래그** | 포즈를 든 채 시각만 이동(점선 테두리). **S**로 그 포즈를 그 프레임에 키 |
| RMB 메뉴 | 키 복사·붙여넣기·삭제·스냅 · 재생 범위를 선택으로/전체로 · 재생 모드·속도 · 키 틱 표시 |
| 레인지 바 끌기 · 양끝 · 더블클릭 | 재생 범위 이동 · 크기 · 전체 ↔ 직전 범위 |
| 길이 칸 | 모션 길이 |
| 재생 표시 연속 / 프레임 맞춤 (24 FPS) | 둘 다 실제 시간. 프레임 맞춤은 가장 가까운 24fps 프레임의 자세만 |

전역 키: **1 / 2** 이전·다음 키, **Shift+W / E / F** 현재 시각의 키 복사·붙여넣기·지우기, **Shift+1 / 2** 인비트윈 빼기·넣기, **Ctrl+Z / Y**(또는 Ctrl+Shift+Z) 되돌리기·다시하기. 창 어디에 포커스가 있든 듣고, 글 입력 칸 안에서만 글자 편집이 우선한다.

## 9. 오브젝트 탭 — 고른 오브젝트 (키가 아니다)

| 항목 | 뜻 |
|---|---|
| 이름 · 부모 | 이름을 바꾸면 채널·스킨 칸이 따라온다. 부모를 바꾸면 밑의 오브젝트도 함께 옮겨진다 |
| 깊이 · 키 | 컷의 맨 위 오브젝트만. far 0 · back 10 · mid 14 · front 16 · close 20. 옆의 **키**가 지금 프레임에 깊이의 키를 놓는다 |
| X · Y · 너비 · 높이 · 회전 · 배율 | 가만히 선 자세 — 애니메이션은 여기에 얹힌다 |
| 색 · 그림을 그린다 · 불투명도를 받는다 | 색 사각형 / 스킨의 그림을 그리는 오브젝트 / 알파 채널을 받는 오브젝트 |
| 안쪽 스킨 · 안쪽 세트 열기 · 여기서 안쪽 고치기 | 세트를 품은 오브젝트(인스턴스)에만 |
| 스킨 (조각 그림) | 입혀 보는 스킨(보기 상태) · 스킨 추가/삭제 · 이름 · 조각마다 그림 |

하이어아키: 클릭 = 고르기, 우클릭 = 더하기 · 세트 넣기 · 따로 보기(솔로 · 숨기기) · 순서 · 부모 · 새 세트로 빼기 · 지우기. **Del** 지우기 · **F2** 이름 바꾸기.

## 10. 내보내기와 문제 칸

- **컷 내보내기…**(컷 목록): 연 컷을 컷 파일(`cut/1`)로 낸다 — 세트는 오브젝트로 펼치고 재생 블록은 키로 구운 한 덩어리, 시각은 프레임. 그림은 복사하지 않고 그 파일 기준 경로로 적는다.
- 빨강 **⚠**는 규칙 위반(내보내기 불가), 노랑 **△**는 경고(내보내기 가능). 고칠 길이 있는 줄에는 **돕는 손** 버튼이 선다(이름 고치기 등 — 되돌리기 한 번).
- 규칙: 이름은 소문자·숫자·`_`, 시각 오름차순, 길이는 0보다 크다. 키는 처음과 끝에 없어도 되고 하나뿐이어도 된다(앞뒤로 그 값이 이어진다).
- 툴바의 **motions.json 가져오기… / 내보내기…** 와 세트 줄의 **rigs.json…** 은 옛 산출물이다. **내보내기 범위**(툴바 콤보): 전체 / 연 세트·컷의 것만.

## 11. 설정 창

툴바 **설정…**: 시간 스냅 간격(1/24 기본 · 1/60 · 1/120) · 새 키 탄젠트 · 시간 표시(프레임/초) · 자동 저장 간격. 바꾸는 즉시 적용, 닫을 때 저장.
시간 스냅 켬/끔과 값 스냅은 그래프 툴바에, Auto Key는 하단 줄에 있다.

## 12. 자주 묻는 것

| 증상 | 이유 · 할 일 |
|---|---|
| 내보내기 버튼이 안 먹는다 | 문제 칸에 ⚠가 있다. 돕는 손을 누르거나 키를 고친다 |
| 키를 놓았는데 성분이 하나만 생겼다 | 바뀐 성분만 키가 된다(마야와 같다). 다른 성분은 값을 넣거나 S로 전부 키 |
| 채널 박스 값이 빨강/주황이다 | 빨강 = 이 시각에 키, 연한 빨강 = 어딘가에 키, 주황 = 키 없는 포즈(S로 키, Esc로 버림) |
| 회전 손잡이가 오브젝트의 원점이 아니라 그림 가운데에 있다 | 원점이 그림 밖이면 그림 가운데에 선다. 각은 그 중심 기준 |
| 뷰포트에 "컷을 열거나 새로 만든다"만 보인다 | 연 것이 없다. 왼쪽 컷 목록에서 고르거나 **새 컷** |
| 모션 추가가 안 된다 | 애니메이션은 연 세트의 것이다 — 세트를 먼저 연다(컷은 타임라인이 하나라 따로 만들지 않는다) |
| Ctrl+Z가 글자만 지운다 | 글 입력 칸 안이다. Enter로 확정하면 포커스가 뷰포트로 가고 그 뒤는 문서 되돌리기 |
| 자동 저장본이 보인다 | `<이름>.autosave.motion-authoring.json`은 5분마다(바뀐 것이 있을 때만). 저장 상태는 건드리지 않는다 |
